OpenMLS browser persistence experiment

Isolated technical experiment only. Never use real accounts, private keys, or user messages. The non-extractable WebCrypto key is stored in the same browser origin. This protects against casual raw-key export, not same-origin script compromise, malware, or browser-profile compromise. This is not production BaddieLink chat.

This test creates a local MLS group, encrypts Bob's serialized MLS storage snapshot with AES-GCM, stores it in IndexedDB, reloads the page, restores Bob's group, and processes a previously received MLS ciphertext.
